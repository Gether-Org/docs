Le Dashboard est le centre de contrôle de Sledge. Il offre une vue globale et en temps réel sur l'état de votre infrastructure multi-cloud.

## Indicateurs de Performance (KPIs)

En haut de l'écran, quatre métriques clés vous permettent de surveiller la santé de vos opérations :
* **Active Connections :** Le nombre de points de terminaison cloud (endpoints) actuellement reliés à Sledge.
* **Total Data Synced :** Le volume total de données transférées (ex: 4.2 TB), avec un indicateur de tendance par rapport au mois précédent.
* **Migration Success Rate :** Le pourcentage de réussite global de vos tâches actives (ex: 99.8%).
* **Failed Sync Tasks :** Le nombre d'erreurs récentes nécessitant votre attention.

## Gestion des Ressources

* **Cloud Providers :** Un tableau récapitulatif liste toutes vos connexions actives (Provider, Nom, Statut, Région, Coût).
* **Recent Activity :** Un journal d'audit détaille les dernières actions effectuées (ex: "Assets Backup" vers GCP, ou "DB Migration" depuis Postgres vers AWS RDS), assurant une traçabilité totale.

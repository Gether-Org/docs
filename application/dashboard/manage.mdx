The management interface (Manage) is the interactive heart of Sledge. This is where you visually design the architecture of your migrations.

## Node-Based Interface (Drag & Drop)

The workspace uses an interactive graph system:
* **Sledge Node:** The central hub of your infrastructure.
* **Provider Nodes:** Drag, drop, and connect your providers (e.g., AWS, Azure, Scaleway) directly to the Sledge node to establish a connection.
* **Controls:** Located at the bottom left, these tools allow you to zoom in, zoom out, or center the view on your resources.

## Interacting with Nodes

Once your providers are added to the workspace, several interactions are available directly from the nodes:

### Explore Data (Double-click)
Double-clicking a provider node opens a sidebar on the right side of the screen. It allows you to list all available "Buckets" (storage spaces) and directly preview the files inside them.

<Frame>
  <img src="/images/manage-bucket.png" alt="Bucket Content" />
</Frame>

### Provider Settings (Right-click)
Right-clicking a node opens a quick context menu. From this menu, you can access specific provider settings to **rename** it, modify its access credentials, or **delete** it from your workspace.

## Add a Provider

To add a new cloud provider, click the main action button (the blue **"+"** button at the bottom right).

<Frame>
  <img src="/images/manage-import.png" alt="Importing a provider" />
</Frame>

### Import from File
The fastest and most secure method to add a provider (e.g., Amazon AWS) is to use the **"Import From File"** modal:
1. Select the target provider from the dropdown menu.
2. Drag and drop your configuration file (supported formats: **JSON, YAML, CSV**, etc.).
3. Sledge automatically parses the file, securely stores the credentials in the database, and instantiates the new node in your workspace.

The "Start Migration" interface allows you to configure your data transfer step-by-step from one cloud provider to another. The view is split into two parts: workflow configuration on the left, and data preview on the right.

## Workflow Configuration

The configuration process is guided and takes place in two simple steps within the left sidebar:

### 1. Source Connection
Define where your data is coming from.
* **Select Connection:** Choose the source cloud provider from your pre-established connections (for example, your AWS account).
* **Bucket:** Select the specific bucket containing the files to migrate from the dropdown menu (e.g., `my-first-sledge-bucket`).

### 2. Destination Connection
Define where your data should go.
* **Select Connection:** Select the destination cloud provider (for example, your GCP account).
* **Destination Bucket Name:** Enter the name of the target bucket. Handy feature: if the specified bucket does not exist yet on your destination account, **Sledge will automatically create it** when launching the migration.

## Preview (Source Contents)

The right panel is dedicated to verifying data before sending it.

* **File Explorer:** Instantly displays the content of the selected source bucket. You can see the exact list of items that will be migrated (for example, your `.jpg` images).
* **Refresh:** A refresh icon at the top right allows you to update the list if recent changes have been made to the source cloud.
* **Statistics:** At the bottom right, a counter summarizes the total volume of items ready to be transferred (number of files and folders).

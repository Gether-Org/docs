L'interface "Start Migration" vous permet de configurer étape par étape le transfert de vos données d'un fournisseur cloud à un autre. La vue est divisée en deux parties : la configuration du flux à gauche, et la prévisualisation des données à droite.

## Configuration du Flux

Le processus de configuration est guidé et se déroule en deux étapes simples dans le panneau latéral gauche :

### 1. Source Connection
Définissez l'origine de vos données.
* **Select Connection :** Choisissez le fournisseur cloud source parmi vos connexions pré-établies (par exemple, votre compte AWS).
* **Bucket :** Sélectionnez dans le menu déroulant le bucket spécifique contenant les fichiers à migrer (ex: `my-first-sledge-bucket`).

### 2. Destination Connection
Définissez où vos données doivent atterrir.
* **Select Connection :** Sélectionnez le fournisseur cloud de destination (par exemple, votre compte GCP).
* **Destination Bucket Name :** Saisissez le nom du bucket cible. Pratique : si le bucket indiqué n'existe pas encore sur votre compte de destination, **Sledge le créera automatiquement** lors du lancement de la migration.

## Prévisualisation (Source Contents)

Le panneau de droite est dédié à la vérification des données avant l'envoi.

* **Explorateur de fichiers :** Affiche instantanément le contenu du bucket source sélectionné. Vous pouvez y voir la liste exacte des éléments qui seront migrés (par exemple, vos images `.jpg`).
* **Actualisation :** Une icône de rafraîchissement en haut à droite permet de mettre à jour la liste si des modifications récentes ont été faites sur le cloud source.
* **Statistiques :** En bas à droite, un compteur résume le volume total d'éléments prêts à être transférés (nombre de fichiers et de dossiers).

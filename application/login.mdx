The login page (Login) is the secure entry point for all Sledge users. It has been designed to be fast, intuitive, and offer multiple authentication methods.

## Interface Features

The design adopts a two-column layout (Split Screen) with an elegant dark theme and our signature blue color. The left side is dedicated to interaction:

<CardGroup cols={2}>
  <Card title="Classic Authentication" icon="envelope">
    Standard login via **Email and Password**. A "Forgot your password?" link allows for quick account recovery.
  </Card>
  <Card title="Social Login (OAuth)" icon="github">
    One-click login (Single Sign-On) via secure third-party providers: **Google** and **GitHub**.
  </Card>
</CardGroup>

## Technical Operation

This page bridges our user interface and our backend security architecture:

1. **Frontend (Next.js):** Session management, redirection, and OAuth providers (Google/GitHub) are handled by **NextAuth.js (v5)**.
2. **Backend (Go):** For classic authentication, credentials are sent to our Go API, which compares them against our **PostgreSQL** database.
3. **Security:** Once the user is verified, a secure **JWT** token (`golang-jwt/jwt/v5`) is generated and sent back to the client to authenticate future actions (such as starting a migration).

<Note>
  **New User Access:** A *Sign up* link is available at the bottom of the interface to redirect to the registration page (see the `Register` section).
</Note>

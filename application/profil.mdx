## Page Structure

Internal navigation through settings is seamless via a tab system (Tabs) located at the top of the page:
* **General:** The default tab, dedicated to personal information.
* **Organizations:** For managing collaborative workspaces and teams.
* **Billing:** For managing payment details, subscriptions, and billing.

### Personal Information (General)

The "Personal Information" interface allows the user (for example, *Esteban Marques* in the screenshot) to view and update:
* A **profile picture** (Avatar).
* The **First Name** and **Last Name**.
* A customizable **Description** to identify the user's role.
* The **Email** linked to the account.

### Data Updates

When the user clicks the **Edit** button, the frontend (Next.js) sends an authenticated API request with the active JWT token. The **Go** backend intercepts this request, validates the new data, and updates the corresponding record in the **PostgreSQL** database before returning a success status to the interface.

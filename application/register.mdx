The registration page (Register) allows new users to join the Merops platform. It retains the same graphic identity and "Split Screen" structure as the login page to ensure a consistent user experience.

## Interface and Features

The interface features a clear form titled "Create an account" to get started with Merops:

* **Classic creation:** Input of email and password, validated by the blue "Sign Up" button.
* **Quick creation (OAuth):** The "Or continue with" option allows for one-click sign-up via a secure third-party account (**Google** or **GitHub**).
* **Navigation:** An "Already have an account? Login" link at the bottom of the form allows users to instantly switch to the login page if they already have an account.

## Backend Logic & Security

Upon submitting the registration form:
1. Our **Go** backend queries the **PostgreSQL** database to verify that the email address is not already in use.
2. The entered password is securely hashed (via `golang.org/x/crypto`) before being persisted in the database. Merops never stores plain-text passwords.
3. Once the account is created, an initial JWT token is generated, and the new user is redirected to their Dashboard.
